Instrument Serif (OFL 1.1): a condensed editorial display serif, regular and italic, for titles and main phrases.

```ts
await host.io.font('assets/fonts/InstrumentSerif-Regular.ttf', 'Instrument Serif')

ctx.font = '112px "Instrument Serif"'
```

A display face: set it large (titles, phrases), and pair it with a sans for names, dates and
captions. Keep `InstrumentSerif-OFL.txt` with the fonts.
