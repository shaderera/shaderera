# Logos and identity

For requests about a logo or mark: a reveal, an ident, a closing mark.

- A supplied logo (SVG) is used as given: same shapes, same proportions, same colours when it is
  printed flat. Do not redraw a supplied logo to make it easier. If the code that reads it cannot
  handle part of it (strokes, text, gradients, transforms), report that instead of dropping it.
- No logo supplied and none asked for: design an original mark only when the brief asks for one,
  and say it is original.
- A mirror-like mark turned straight to the camera can render black (`product-3d.md` has the
  fix).
- Review's `end-hold` check measures how long the closing frame holds still. Check that the mark
  is readable at the smallest delivered size.

Check with review, and look at the final frame and one mid-reveal frame at full size
(`npx shaderera still <t>`).
