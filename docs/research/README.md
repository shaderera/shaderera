# Research

Evidence gathered before a decision, kept so the decision can be reopened with its sources. Each
page says what it fed and what has happened since. Claims cite their sources inline; _(secondary)_
marks ones that rest on forums or aggregators.

- [plugin-naming.md](plugin-naming.md): how about thirty tools name and install add-ons, what
  renames cost, and the `npx` hole. Fed [0014](../adr/0014-plugins-in-one-cli.md).
- [plugin-direction.md](plugin-direction.md): what the official plugins should become and how
  they reach people: registries, agents, security, hosting and the ad market, with the status of
  each recommendation. Fed 0014.
- [reference-still-capture.md](reference-still-capture.md): copying a still reference (a poster,
  a screenshot, a website's hero): style facts over CDP, OCR with Thai, font identification,
  measuring a still clone, and the rights a guide should state. Fed 0032.
- [reference-motion-capture.md](reference-motion-capture.md): whether CDP virtual time or an
  injected clock captures GSAP and spring motion from an outside page frame by frame, and whether
  that capture is a plugin or core, with six experiments. Fed [0032](../adr/0032-reference-copying.md).
