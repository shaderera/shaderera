# Skills from other repositories

Copied so every agent working in this repository has them. Each SKILL.md has one change: `metadata.internal: true` in its frontmatter, so `npx skills add shaderera/shaderera` offers only the Shaderera skills. To update, copy them again from the same place and add that line back.

| Skills | From | Commit |
|---|---|---|
| `ponytail`, `ponytail-review`, `ponytail-audit`, `ponytail-debt`, `ponytail-gain`, `ponytail-help` | [dietrichgebert/ponytail](https://github.com/dietrichgebert/ponytail) `skills/` | 9b58c1f |
| The 27 skills its Claude Code plugin lists (`engineering/` and `productivity/`; not `misc/`, `in-progress/` or `deprecated/`) | [mattpocock/skills](https://github.com/mattpocock/skills) | 49dd158 |

Ponytail's plugin also has hooks and an always-on rule; those are not copied, only the skills.
